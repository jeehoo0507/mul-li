# 옴의 법칙과 키르히호프 법칙으로 숫자를 읽는 회로

저항으로 계산하는 아날로그 인메모리 컴퓨팅을 실제 신경망에 적용해 본 시뮬레이션과 시각화 사이트입니다.
손글씨 숫자를 고르면, 가중치를 저항의 컨덕턴스로 담은 크로스바 회로가 3층 신경망(64 → 32 → 16 → 10)을 계산하는 과정을 단계별로 볼 수 있습니다.

**실험 정리 문서: [EXPERIMENT.md](EXPERIMENT.md)** · 시각화 사이트: [jeehoo0507.github.io/mul-li](https://jeehoo0507.github.io/mul-li/)

### 사이트에서 할 수 있는 것

- **숫자 고르기**: 예시 30개 중 하나를 고르면 회로가 처음부터 계산을 재생합니다. 빨간 숫자는 열악한 칩에서 자주 틀리는 예시입니다.
- **단계별 회로 뷰어**: 층마다 다섯 단계를 보여줍니다.
  1. DAC: 이전 층의 값을 행 전압으로 바꿈
  2. 곱셈: 교차점마다 I = G·V (셀 밝기 = 전류)
  3. 덧셈: 열을 따라 전류가 합쳐짐 (키르히호프 전류 법칙)
  4. 차동 + ADC: I⁺ − I⁻ 를 TIA와 ADC로 읽음 (파란 눈금 = 디지털 정답값)
  5. ReLU → 다음 층 (마지막 층은 가장 큰 출력이 답)
- **셀 위에 마우스**: 그 교차점의 G⁺, G⁻, 전압, 전류를 실제 수치로 보여줍니다.
- **칩 설정**: 소자 편차, 컨덕턴스 단계 수, ADC·DAC 비트, IR drop, 읽기 잡음을 바꾸고, 학습 방식(일반 / 하드웨어 인식)과 열별 보정을 켜고 끌 수 있습니다.
- **결과**: 이 숫자의 확률 분포(디지털 vs 칩), 층별 오차, 테스트 숫자 540장 전체 정답률이 설정을 바꿀 때마다 다시 계산됩니다.

## 물리 모델

| 회로 요소 | 하는 일 | 식 |
|---|---|---|
| DAC | 입력값 → 행 전압 (0 ~ 0.2 V) | V = x · V_read / x_max |
| 교차점 저항 | 곱셈 (옴의 법칙) | I = G · V |
| 열 배선 | 덧셈 (키르히호프 전류 법칙) | I_j = Σᵢ G_ij · V_i |
| G⁺ / G⁻ 두 배열 | 음수 가중치 (차동) | w ∝ G⁺ − G⁻ |
| TIA + ADC | 열 전류 → 전압 → 숫자 | V_out = −I · R_f |
| 바이어스 | 항상 V_read 가 걸리는 추가 행 | |

비이상성:
- **소자 단계 수**: 컨덕턴스를 정해진 단계로만 쓸 수 있음
- **소자 편차**: 써진 컨덕턴스 G' = G (1 + ε), ε ~ N(0, σ²)
- **IR drop**: 구동부와 읽기부에서 멀수록 셀에 걸리는 전압이 줄어듦 (거리 비례 단순 모델)
- **열잡음**: 열마다 √(4kTB · ΣG)
- **읽기 잡음, DAC/ADC 양자화**

## 실험 결과 (칩 10개 평균)

디지털 정확도 97.6%.

| 설정 | 일반 학습 | 하드웨어 인식 학습 | 열별 보정 |
|---|---|---|---|
| 보통 칩 (σ 5%, ADC 8비트) | 97.6% | 97.7% | 97.8% |
| 소자 편차 σ = 30% | 86.5% | 92.6% | 96.5% |

- **체계적 오차는 보정으로 잡힌다**: IR drop의 출력 오차는 열별 보정으로 22% → 2%, 소자 편차와 단계 수 오차는 약 절반으로 줄어듭니다.
- **무작위 오차는 안 잡힌다**: ADC 양자화, 읽기 잡음, DAC 오차는 보정해도 그대로입니다. 정밀도는 결국 하드웨어로 사야 합니다.
- **ADC는 4~5비트가 경계**: 5비트 이상이면 디지털과 거의 같고, 3비트 이하에서 급격히 떨어집니다.
- **오차는 층마다 누적**: 1층 5.6% → 2층 7.0% → 출력층 12.1%.

## 폴더 구조

```
index.html                 사이트 (데이터 내장, 이 파일 하나로 동작)
src/index.template.html    사이트 원본 (데이터 자리 __DATA__)
tools/build_site.py        학습된 가중치와 데이터를 넣어 index.html 생성
sim/sim.py                 MLP 학습 + 아날로그 칩 시뮬레이션 + 실험
sim/figs.py                그림 생성 (회로도, 정확도·오차 분석)
sim/extra_figs.py          추가 그림 (데이터·구조, 학습 곡선, 가중치→컨덕턴스, 신호 흐름, 칩별 편차)
sim/out/                   results.json, params.npz
figures/                   결과 그림
figures/circuit/           부품 회로도 (곱셈, 덧셈, 뺄셈, TIA, 크로스바, 로그 증폭기)
```

## 다시 만들기

```bash
pip install numpy scikit-learn matplotlib
python sim/sim.py          # 학습과 실험 → sim/out/
python sim/figs.py         # 그림 → sim/out/
python sim/extra_figs.py   # 추가 그림 → sim/out/
python tools/build_site.py # index.html 다시 생성
```

데이터는 scikit-learn에 내장된 8×8 손글씨 숫자(1797장, 학습 70% / 테스트 30%)를 씁니다.
브라우저의 시뮬레이터는 `sim.py`와 같은 모델을 JavaScript로 옮긴 것으로, 모든 비이상성을 끄면 디지털 계산과 10⁻⁷ 이내로 일치하고 통계적 정확도도 Python 결과와 맞는 것을 확인했습니다.
